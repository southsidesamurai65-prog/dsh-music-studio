# 作曲：按参考风格写原创曲

把一个“像某某”的请求，变成**可测量的参数 + 可复现的合成脚本**。参考曲只提供风格特征，旋律与编曲必须原创。

## 何时使用

用户说“写一首像 X 的曲子”“想要 Y 风格”“这首太慢/太吵/不够江南，改一下”时。

## 工作流

0. **列编配清单**（在写简报之前）：按角色各选一件乐器——节奏组、主奏、低音、
   色彩、铺底、空间。清单必须能和最近做过的曲子逐项对比（见下节“抗同质化”）。
   没有节奏组的曲子（室内乐、纯民乐）也要显式写“无节奏组”。
1. **探测**：对每首参考曲调用工具 `music_style_probe`（路径参数为音频文件）。读回速度、调性、和弦循环、音色、空间、动态、结构。
   - 工具给出的是**假设**：和弦在无根音配置/重混响素材上会退化，若用户能提供和弦表或 MIDI，以用户为准。
   - 参考曲若不易获取，就用文字特征（BPM、调式、编制、年代）代替。
   - `arrangement` 字段是**关于“有没有节奏组”的线索**，不是事实：
     `onsets`（每秒起音数）高 = 编配密；`low-band pulse` 强且 `periodicity` 高 =
     低音有周期性脉冲（多半有底鼓/大鼓）；`backbeat` > 1.15 = 二四拍比一三拍重
     （流行鼓组的军鼓位）；`presence` 高 = 1–2 kHz 靠前（人声/主奏靠前）。
     这些数字**看不出**具体是钢琴还是古筝，必须配合频谱图和你自己的编配清单判断。
   - `fingerprint` 是**音色行为**：`attack_ms`（三段频带的起音时间，ms）、
     `decay_ms`（衰减到一半的时间）、`flatness`（每段“噪声化”程度，0 纯音、1 白噪）、
     `sustain_ratio`（持续音占比）。用法：把**成品和参考放在同一组数上对比**——
     比如参考 high 段 flatness 0.56、你的 0.30，说明参考的高频更“噪”（镲片/气声/噪声底），
     你的偏干净；参考低段起音 12 ms、你的 75 ms，说明参考更钉、你的更拖。
     它同样不给乐器名，也受母带影响：商用成品和自渲染在同一份指标上天生有差异。
2. **写简报**：按六层展开（见下），每层给出具体数值或乐器名，并写明**不要什么**。把简报回给用户确认（若用户已明确，可直接开工）。
3. **合成**：新建 `compose_<name>.py`，`import synth_lib as sl`（路径见下），用 numpy 合成。结构上先定 BPM/调性/和弦，再写旋律，再加伴奏，最后混音。**渲染时就分轨**（`sl.Stems`），别等到混音再拆。
   - 固定随机种子 `sl.seed(7)` 保证可复现。
   - 每件乐器写成 `(bar, beat, midi, dur, velocity)` 的数据表，方便改。
4. **验证**：对成品再跑一次 `music_style_probe`，对比 BPM、调性、频段平衡、宽度、动态弧与参考的差距；用 ffmpeg 画波形/频谱图检查结构与削波。
5. **迭代**：一次只改一层。用户说“太吵”改配器密度，“不够亮”改音区与高频，“不连贯”改句法（共同音衔接、动机贯穿），不要同时改五样。

## 六层简报模板

```text
【体裁/年代】lo-fi hip hop，2010s 末，卧室制作感
【参考】A《…》— 要它鼓的拖拽感；B《…》— 要它电钢琴的和弦色彩
【速度/律动】84 BPM，4/4，swing 约 55%，鼓点稀疏
【调性/和声】A 小调；Am9–Fmaj9–Cmaj9–G6/9，每和弦一小节
【编制】Rhodes、失谐锯齿铺底、无品贝斯、刷鼓
【音色/制作】暖，低通 ~8 kHz，磁带饱和，板式混响 ~2 s，宽度 0.3
【编配】节奏组：鼓组（底鼓 1/3、军鼓 2/4、闭镲八分）｜主奏：二胡｜低音：电贝斯
【结构】前奏 4 小节 → 主段 8 → 收尾 4；结尾留残响
【不要】失真吉他、808、人声、EDM riser
```

## 抗同质化：编配清单与差异检查

同一个题材做多了，最容易撞的不是旋律，而是**织体**：同样的“持续线条 + 拨弦琶音 + 长混响”。
开工前先写清单，收尾前逐项对比最近 2–3 首：

| 角色 | 本曲 | 最近一首 | 是否重复 |
|---|---|---|---|
| 节奏组（或“无”） | | | |
| 主奏 | | | |
| 低音 | | | |
| 色彩乐器 | | | |
| 铺底 | | | |
| 混音性格（干/湿、亮/暗） | | | |

**规则**：六项里如果有 4 项相同，就至少换一项，并且换的是**承重项**
（节奏组、主奏、低音），不是把古筝换成扬琴这种同一个角色内部的替换。

其它三条：

- 不复制上一首的脚本当起点。从 `templates/` 里挑一个**和上次不同的**模板新建，
  不要 `cp` 上一首的 `compose_*.py` 改参数。
- 每首曲子建自己的目录 `pieces/<name>/`，脚本、音频、图都放里面，方便日后 A/B。
- 混音参数每首重新核对（见“混音预设”），不要沿用上一首调好的那套。

## 和声：用级数，不用音高表

```python
import harmony as hm
KEY = hm.Key("D")
prog = ["Imaj7", "V/3", "vim7", "IVmaj7", "I/3", "iim7", "Vsus4", "V7"]
voicings = hm.realize(prog, KEY)      # 四个声部，每个都从前一个就近移动
```

- 和弦写成**级数 + 性质**：`I` `vi` `V7` `ii7b5` `bVI` `#IVdim7`，也接受 `Dmaj7` 这类绝对写法。
- `V/3` 是第一转位（三音在低音），`V/V` 是副属（属和弦的属），`I/C` 是指定低音。
- `realize` 做三件事：就近移动、禁止平行五八度、每个声部留在自己的音区。
  声部数按和弦自动取（九和弦用五个声部）。
- **实测**（16 小节、同一段旋律、只换排法）：块状排法总位移 159 个半音、9 处平行五八度；
  就近排法 91 个半音、0 处平行。
- **探针看不出这个差别**（音色重心只差 25 Hz）。这类改进只能靠耳朵，以及乐谱级指标
  `hm.motion_total()` / `hm.parallels()`——别指望跑一遍探针就能验收声部进行。

### 变化和弦与功能生成（1.7.2）

```python
p = hm.Progression(hm.Key("D"), 8).generate(cadence="PAC", chromatic=2, seed=5)
p.roman()   # ['vi', 'V7/V', 'V', 'I', 'V7/IV', 'IV', 'V', 'I']
p.names()   # ['Bm', 'E7', 'A', 'D', 'D7', 'G', 'A', 'D']
p.validate()                        # []  —— 副属有没有解决
hm.check_melody(MELODY, p, hm.Key("D"))   # 强拍上的 b9 与三全音
```

- 生成器先填**功能骨架**（主 → 下属 → 属 → 主），再花**变化预算**：副属 `V7/x`、
  借用 `bVI`/`bVII`/`iv`、三全音替代 `bII7`。插入必须向前解决，两个变化和弦不相邻。
- `chromatic` 是每 8 小节最多几个变化和弦。不设预算，到处都是属七，听两句就腻。
- `check_melody` 只报两种冲突：根音上的 b9、与根音成三全音的音。
  11 度、6 度、大七度是色彩，不是冲突——都报就会变成狼来了。
- 探针新增 `chroma_novelty`（相邻小节 chroma 的距离）：平铺进行 0.389，变化进行 0.464。
  但**它测的是变化速率，不是丰富度**，和声质量只能靠乐谱和耳朵。

### 转调：用枢轴，不要硬切（1.7.3）

```python
p = hm.Progression(hm.Key("D"), 16).generate(cadence="PAC", chromatic=2, seed=3)
p.modulate(hm.Key("B", "minor"), at_bar=9, cadence="PAC", seed=1)
# 枢轴: Em = ii in D / iv in B minor
```

- 枢轴必须是**两个调都自然**的和弦：D 大调转 b 小调时，Em（ii → iv）、G（IV → VI）、
  A（V → VII）都是好选择；生成器优先挑在新调里本来就有功能的那种，避开“变成三级”的弱枢轴。
- 前 8 小节留在旧调、枢轴落在第 9 小节、之后在新调里重新生成到终止式。
- 转调点最容易出**旋律冲突**：`check_melody` 在 D→b 小调的例子里抓到 G 对 F#（b9），
  改成 F# 就好了。先跑检查再听。
- **探针只报一个调**（整首一个全局结果）。要验证转调，必须按段落切开分别测：
  这次例子整曲报 B minor（后半段主导），后半段单独测才是干净的 B minor。

## 混音：先分轨，再上总线

**渲染时就分轨**，不要等到混音再分——信号一旦相加就再也拆不开。

```python
import synth_lib as sl, mix as mx
st = sl.Stems(N / SR)                      # roles: drums / bass / music / fx
st.add("drums", sl.kick(), t0, 0.0, 0.9)   # 或 st.play("snare", sig, t0) 按角色自动分
st.add("music", sl.piano(m, 2.0), t0, 0.2, 0.5)
st.add("fx",    sig, t0, 0.1, 0.2)         # fx 只进混响发送，不进干声
ir = mx.load_ir("ConradPrebysConcertHall.wav")
bus = mx.mixdown(st, preset="pop", ir=ir)  # 一条链出成品
```

`mixdown` 的链路：

```
drums ──▶ 胶水压缩(慢起音) + 并联压缩(快起音) ──┐
music ──▶ 均衡 ▶ 多段压缩 ─────────────────────┼──▶ 求和 ▶ 宽度 ▶ 段落增益
send  ──▶ 实测脉冲响应 ▶ 湿声返回 ─────────────┘        ▶ 对准响度 ▶ 限幅 ▶ 膝削波
```

要点：

- **鼓不进多段压缩**。军鼓瞬态就在 200–2000 Hz 那一档里，整条总线压过去
  会把它和铺底一起压平。实测（《兰亭一页》177 s）：整条压缩反拍 1.68，
  分轨后 1.92，原始素材 2.01——瞬态保留率 84% → 96%。
- **鼓总线**用慢起音（20–35 ms）让槌击穿过去，再混一小份快起音、8:1 的
  并联压缩补密度；输出峰值归一化回输入，这就是它的补偿增益。
- **别调响度去救鼓**。把鼓推大 2–4 dB 不会提高反拍比，只会让限幅器更用力，
  数字反而降（实测 +4 dB：1.92 → 1.88）。
- **宽度按目标解，别用固定倍率**：窄声场的合成素材和宽声场的采样素材需要
  不同的侧面增益，预设里存的是目标值（`width_target`），`mixdown` 自己解。
- **限幅器要带补偿**。释放时间总是滞后，输出会停在峰值下方 2–3 dB、crest 偏低，
  听起来“响但扁”。`limiter(..., makeup=True)` 把这段余量还回去。
- **软削波是膝削波**，只削过膝的那几 dB。拿 tanh 套整条信号是压缩不是削波
  （实测峰值白掉 2.4 dB、反拍 1.92 → 1.83）。
- 目标参考：crest 10–13 dB、RMS 对齐参考、宽度 0.35–0.45。

## 混音预设

`sl.MIX_PRESETS` 是**起点**（响度目标、宽度目标、鼓总线、多段压缩档）：

| preset | 适用 | 响度目标 | 宽度目标 | 鼓胶水 | 并联 |
|---|---|---|---|---|---|
| `chamber` | 民乐室内、丝竹 | −17 dBFS | 0.35 | 2.2:1 @ −17 dB | 0.20 |
| `pop` | 流行、中国风流行 | −13 dBFS | 0.42 | 2.4:1 @ −16 dB | 0.25 |
| `lofi` | lo-fi、卧室 | −14.5 dBFS | 0.25 | 2.0:1 @ −19 dB | 0.30 |
| `cinematic` | 管弦、影视 | −17.5 dBFS | 0.45 | 3.0:1 @ −14 dB | 0.30 |

用预设起步，然后**对成品跑探针**，把 `centroid_hz / width / crest_db / backbeat_ratio`
和目标区间对齐；对不上就改对应的一项，别把整套参数搬过来。

没有鼓的曲子照样可以分轨（鼓分轨为空，`mixdown` 会跳过）；没有实测 IR 时
用 `sl.make_ir(2.2, 1.05, 180, 6500)` 合成一条。最小骨架：

```python
import synth_lib as sl, mix as mx
sl.seed(7)
st = sl.Stems(60.0)
st.add("music", sl.guzheng(sl.midi2f(69), 1.0, 0.8), 0.0, -0.2, 1.0)
bus = mx.mixdown(st, preset="chamber", ir=sl.make_ir(2.4, 1.0, 200, 6500))
sl.write_wav("sketch.wav", bus)
```

想听总线到底做了什么：`mx.write_stems("out", st)` 会把每条分轨单独写成 wav。

## 探针的灵敏度（消融实测）

`assets/ablate.py` 用同一份素材做**配对**实验：只改一个维度，看哪个指标动了、
动多少、别的指标有没有被牵连。跑一次约 30 秒，改探针后应当重跑：

```sh
python3 {{ASSETS}}/ablate.py            # 表格 + 判定
python3 {{ASSETS}}/ablate.py --keep /tmp/ab   # 留下 wav 自己听
```

实测效应量（28 秒、76 BPM、D 大调、鼓+贝斯+钢琴+弦乐铺底+主奏）：

| 改动 | 主要变化 | 结论 |
|---|---|---|
| 去掉鼓组 | 反拍 **2.29 → 1.18**，低频脉冲周期性 0.77 → 0.61 | 反拍比可信 |
| 主奏 弓弦→拨弦 | 中频起音 **34.8 → 29.0 ms**，高频平坦度 +0.07 | 可信，但混响会把差距抹平 |
| 去掉铺底 | 250–500 Hz **−2.7 dB**，宽度 −0.10 | 可信（铺底主要在 250–500，不在 500–1 k） |
| 低通 3 kHz | 重心 **728 → 489 Hz**，4–8 k **−9.8 dB** | 可信 |
| 侧面 ×2.2 | 宽度 **0.21 → 0.46**，其它几乎不动 | 最干净的一对 |
| 混响 0.25→0.60 | 尾比 0.66 → 0.70（+0.05） | 弱，只能看趋势 |
| 响度 −16→−12 dBFS | crest **15.0 → 11.8**，重心 +25 Hz | 响度主要动动态，几乎不动音色 |
| 整条总线压缩 | 反拍 **2.29 → 1.60**，重心 **+218 Hz** | 压缩会同时改反拍和音色 |

三个必须记住的陷阱（都是实测，不是推测）：

- **反拍比不是“有没有鼓”的检测器。** 低通 3 kHz 就能把它从 2.29 推到 3.30：
  它比较的是节拍位置上的全频段瞬态通量，谱平衡一变它跟着变。跨曲比较时要
  先把亮度拉齐。
- **起音密度不是“编配密不密”。** 去掉鼓之后它反而从 2.31 升到 3.23：响的宽频
  瞬态把自适应阈值抬高了， quieter 的钢琴音就检测不到。别拿它判断“够不够满”。
- **没有鼓时速度会判成二倍**（76 → 152）。钢琴八分音符的脉冲被当成拍子。
  遇到 2× / 0.5× 候选时，看 `tempo.candidates` 而不是只看第一个数。

推论：**同一首曲子不同版本之间比较才可靠**，跨曲子比较要先控制响度、亮度、
混响三个变量，否则你比的是母带不是编配。

## 边界

- 不复制参考曲的旋律、和声进行逐音或标志性音色；只学速度、调式、编制、织体、制作手法。
- 不要用艺人名字做商业宣传；商用前提示用户做相似性审查。
- 听不到声音时，用探针数字、频谱图与配器逻辑判断，并在交付说明里讲清哪些是推断。
- 不要把上一首的 `compose_*.py` 当模板复制；从 `templates/` 里挑一个不同的起步。
