# 音乐工作室

把“写一首像这些歌的曲子”变成**可测量的参数**和**可复现的渲染**。

这个 bundle 给 DSH 配置加上两样东西：

- **`music_style_probe`**：分析参考音频（wav/mp3/m4a/flac），返回速度与小节网格、调性
  （含候选）、逐小节和弦估计与循环、音色（频谱重心、频段平衡）、立体声宽度、混响尾巴、
  动态与编排弧线。**逐小节和弦是估计值**，无根音配置或重混响素材上会退化；用户能给和弦表
  或 MIDI 时以用户为准。
- **`compose-in-style`**：技能，携带完整工作流——探测参考、写六层简报、用内置合成库渲染、
  用同一个探针验收、再逐层迭代。

## 依赖

- `python3` + `numpy`
- `ffmpeg`（解码非 WAV 输入）

## 资源

| 路径 | 用途 |
|---|---|
| `assets/style_probe.py` | 工具调用的分析探针 |
| `assets/synth_lib.py` | 加法合成乐器：古筝、笛、箫、二胡、琵琶、扬琴、笙、电钢、铺底、贝斯、鼓、铃、锣，以及钢琴/弦乐/电贝斯/军鼓/沙锤/小提琴/大提琴/合唱/拍手；含角色表与混音预设 |
| `assets/templates/lofi.py` | lo-fi 完整示例（49 秒） |
| `assets/templates/jiangnan.py` | 江南风格完整示例（109 秒） |
| `assets/templates/pop_ballad.py` | 流行抒情起点（钢琴/弦乐/鼓/贝斯 + 独奏主旋律） |
| `assets/STYLE_GUIDE.md` | 长文方法论 |

## 示例

1. `music_style_probe({ path: "/music/reference.mp3" })`
2. 依据画像写简报，再写 `compose_track.py`，`import synth_lib`（路径由技能给出）。
3. 渲染后再次探测，对比速度、调性、频段平衡、动态与参考的差距。

## 编配线索（0.3.0 起）

探针的 `arrangement` 块试图回答“这个混音里有没有节奏组、编配多密”：

| 字段 | 含义 | 读法 |
|---|---|---|
| `onset_rate_per_s` | 每秒起音数 | < 3 稀疏；3.5–7 中等；> 7 很密 |
| `low_pulse_mod` | 30–160 Hz 包络调制深度 | 越大说明低音起伏越明显 |
| `low_pulse_periodicity` | 低音调制在小节拍点上的归一化自相关 | 高 = 有周期性低频脉冲（多半是底鼓/大鼓） |
| `backbeat_ratio` | 二四拍与一三拍的起音强度比（在四种拍位轮换里取最大） | > 1.15 说明有交替重音（多半是军鼓落在反拍）；≈1 说明重音均匀 |
| `presence_db` | 1–2 kHz 相对 200–500 Hz | 高 = 主奏/人声靠前 |
| `texture` | sparse / mid / busy | 起音密度的粗分类 |

这些都是**启发式**：它们听的是混音信号，不是总谱。区分不了钢琴和古筝，也会被
 tempo 对半/倍增影响。用来和参考曲做相对比较，不要当结论。

## 音色行为（1.1.0 起）

`fingerprint` 是**关于“怎么发声”的描述**，不是乐器识别：

| 字段 | 含义 | 能看出什么 |
|---|---|---|
| `attack_ms` | 低/中/高三段频带的起音时间中位数 | 钉（<15 ms）vs 拖（>50 ms，弓弦/铺底） |
| `decay_ms` | 峰值衰减到一半的时间 | 拨弦/鼓短，钢琴/弦乐长 |
| `flatness` | 每段频谱的“噪声化”程度（0 纯音，1 白噪） | 镲片、气声、噪声底多不多 |
| `sustain_ratio` | 持续音帧占比 | 织体是长音撑的还是点状堆的 |

用**同一组数**比较成品与参考，而不是当绝对判据。它分不出钢琴和古筝——
那需要分离音源（stem separation）或逐音起音分析，超出了这个探针的范围。
另外商用母带和自渲染在同一份指标上会系统性偏离（噪声底、母带染色）。

## 采样音色（1.2.0 起）

`assets/sf2.py` 是一个最小 SoundFont 2 读取器（纯 numpy）：解析 phdr/pbag/pgen/inst/
ibag/igen/shdr/smpl，按音区与力度选采样，做线性插值变调、循环点、音量包络、
衰减与声像。`synth_lib.use_soundfont(path)` + `synth_lib.sf_play(program, bank)`
返回和合成乐器同签名的函数。

刻意不做：滤波器、LFO、调制矩阵、立体声采样（只取单声道）。够用来编曲，不是完整合成引擎。

**授权**：音色库不随插件分发。GeneralUser GS 等库各有自己的许可，商用前必须自己确认；
插件里只放代码和说明。

## 句法（1.4.0 起）

`assets/phrase.py` 把“写旋律”变成“对一个动机做操作”：移调模进、倒影、逆行、
时值扩大/缩小、片段、加花、终止式、微时序人性化。动机用**音级**表示，
所以移调和倒影都留在调内。`render()` 把音级映射成 (时间, 时值, MIDI, 力度)。

示例工程 `pieces/dengxia/compose_dengxia.py` 用同一动机写出 A A′ B A″ 四段：
呈示、上行模进加花、倒影换音区、时值扩大收束。

## 分轨与混音（1.3.0 起，1.5.0 分轨化）

`synth_lib.Stems` 把渲染结果按角色分开（`drums` / `bass` / `music` / `fx`）。
`fx` 是**只送混响**的发送总线，不参与干声求和。分轨的意义只有一条：
混音阶段还能不能把军鼓从铺底里分出来。

`mix.mixdown(stems, preset, ir=…)` 的链路：

1. 鼓 → `drum_bus()`：按峰值归一到 −3 dBFS（让阈值可移植）→ 慢起音胶水压缩
   （20–35 ms，瞬态通过）→ 混入一份快起音、8:1 的并联压缩（补密度）→
   峰值归一化回输入，权重即补偿增益。
2. 其余 → 均衡钩子 → `multiband_compress`（零相位分频、软拐点）。
3. 发送总线（`drum_wet·鼓 + reverb_wet·其余 + fx`）→ 实测脉冲响应卷积 → 湿声返回。
4. 求和 → 宽度（按 `width_target` 解出侧面增益，上限 6 倍）→ 段落增益 →
   对准 `target_rms_db` → 限幅 → 膝削波。

两条实测结论写进了代码注释：多段压缩放在整条总线上会把反拍从 2.01 压到 1.63；
限幅器的增益包络若用**居中**窗口平滑，会在每次军鼓前 45 ms 开始压，等于自己
把要保的瞬态压平。现在限幅器在 1.45 ms 块网格上做前视最小值 + 释放，
并用 `makeup` 把释放滞后留下的 2–3 dB 余量还回去。

`soft_clip` 是膝削波（低于拐点完全线性），不是套在整条信号上的 tanh——
后者会让峰值白掉 2.4 dB、反拍掉 0.09。

## 消融基准（1.6.0 起）

`assets/ablate.py` 回答一个探针必须回答的问题：**每个数字会不会在它的成因
变化时变化**。做法是渲染一份 28 秒的素材（鼓/贝斯/钢琴/铺底/主奏分轨），
再成对地只改一个维度混一遍，然后问探针：

| 配对 | 必须成立的移动 | 实测 |
|---|---|---|
| 去掉鼓组 | 反拍比↓、低频脉冲周期性↓ | 2.29 → 1.18 / 0.77 → 0.61 |
| 弓弦→拨弦 | 中频起音↓ | 34.8 → 29.0 ms |
| 去掉铺底 | 250–500 Hz↓ | −2.7 dB |
| 低通 3 kHz | 音色重心↓、4–8 k↓ | −239 Hz / −9.8 dB |
| 侧面 ×2.2 | 宽度↑ | 0.21 → 0.46 |
| 混响 0.25→0.60 | 尾比↑ | 0.66 → 0.70 |
| 响度 −16→−12 dBFS | RMS↑、crest↓ | +3.2 dB / −3.2 dB |
| 整条总线压缩 | crest↓ | −0.9 dB（反拍 −0.69） |

用途有两个：**回归**（改探针后跑一遍，`must` 不成立时退出码为 1）和
**标尺**（知道多小的差是真差）。

顺带测出三个假阳性陷阱，已写进技能文档：反拍比会被谱平衡带着走（低通 3 kHz
能把它推高 1.0）；起音密度在去掉鼓之后反而上升（自适应阈值被响的瞬态抬高）；
没有鼓时速度会被判成二倍。

这套基准上线时立刻抓到两个真 bug：`make_ir` 生成的脉冲响应比实测 IR 小
11–14 dB（合成混响一直远比 `wet` 参数听起来的干），以及限幅器用居中窗口
平滑增益导致每次击打前 45 ms 就开始压。

## 抗同质化

合成库偏科时，任何同题材请求都会落到同一套织体上（“持续线条 + 拨弦琶音 + 长混响”）。
0.3.0 的应对：

- 技能要求先写**编配清单**（节奏组/主奏/低音/色彩/铺底/混音性格），收尾时与最近
  2–3 首逐项对比；六项里四项相同就必须换一个承重项。
- `sl.INSTRUMENTS` 按角色列乐器，`sl.palette(preset)` 打印角色表与混音起点。
- `sl.MIX_PRESETS` 提供 chamber / pop / lofi / cinematic 四套起点（响度目标、宽度目标、
  鼓总线、多段压缩、峰值），避免沿用上一首调好的参数。
- 明确禁止复制上一首的 `compose_*.py`，改为从 `templates/` 里挑不同的起点。

## 说明

- 全部从零合成，不含采样素材。
- 设置随机种子（`synth_lib.seed(n)`）后渲染可复现。
- 不上报遥测，只写 agent 自己创建的文件。
